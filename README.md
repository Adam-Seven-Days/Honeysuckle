# 金银花 (Honeysuckle)

> 一个原生、纯客户端直连的哔哩哔哩第三方安卓客户端。

金银花使用 Kotlin 与 Jetpack Compose 构建，界面与播放链路均为原生实现。应用不依赖自建服务器，不接入统计、广告或推送 SDK；登录、历史、收藏与偏好都只留在你的设备上。

> 本项目为非官方作品，与哔哩哔哩官方无任何关联、合作或授权关系。

## 功能

### 浏览

- 首页「推荐 / 热门」信息流，支持下拉刷新与连续翻页
- 直播列表与直播间播放
- 番剧排行、追番表与番剧详情
- 动态时间线（登录后可用）
- 视频搜索、搜索联想与搜索历史

### 播放

- 详情页取流，支持画质切换、倍速、全屏与多 P 自动连播
- 亮度、音量手势，长按画面临时加速
- 自研弹幕渲染内核，支持透明度、字体大小、显示区域、密度、速度、流畅度与屏蔽词
- 后台播放、画中画与应用内小窗

### 账号与互动

- 扫码登录与账号密码登录
- 多账号分桶保存，可切换、移除与退出
- 点赞、投币、收藏、关注、发弹幕与评论点赞
- 观看历史、收藏夹与「接着看」

### 界面

- 「墨黑 + 金银花琥珀」配色，跟随系统 / 浅色 / 深色三档
- 现代扁平 + Bento 布局，手机底栏与宽屏侧栏
- 文字、图标、按钮、弹窗、开关等组件均为仓内自绘

### 设置

- 外观与首页：主题档、主题色四选一、首页默认档位、双列 / 单列排布
- 导航栏：动态 / 直播 / 番剧三格各自显示或收起
- 开播：自动播放（总是 / 仅 Wi-Fi / 从不）、默认清晰度、播放时屏幕常亮、后台播放、全屏方向、记住播放亮度
- 速度、画中画、手势、多 P 自动连播、AB 循环与观看历史
- 下载：只在 Wi-Fi 下缓存、缓存清晰度（可跟随当前播放档）
- 弹幕：总开关、透明度、字体大小、滚动区域、滚动 / 顶部 / 底部三类、密度、速度与屏蔽词
- 评论：默认排序、点赞只读、楼中楼显示点赞
- 每一组都可以单独「恢复本组默认」；存储与缓存页只清缓存，不碰历史、收藏与离线视频

## 隐私

- 不收集、不上传你的个人数据
- 没有自建服务器、中转、统计、广告或推送服务

## 技术栈

| 层 | 选型 |
| --- | --- |
| 语言与 UI | Kotlin、Jetpack Compose |
| 播放 | AndroidX Media3 / ExoPlayer |
| 依赖注入 | Hilt |
| 本地存储 | Room、DataStore |
| 网络 | OkHttp、kotlinx.serialization |
| 图片 | Coil |
| 工程结构 | Gradle 多模块 |

## 构建

需要 JDK 21 与 Android SDK 37。

```bash
./gradlew :app:assembleDebug
```

发布包：

```bash
./gradlew :app:assembleRelease
```

发布签名所需的 keystore 只保存在维护者本机，不随仓库提供。没有签名文件时构建仍可完成，产物为未签名包。

代码检查：

```bash
./gradlew ktlintCheck detekt
```
