## 一句话

**本应用不上传任何东西。** 没有自建服务器,没有中转,没有统计、广告或推送 SDK。

## 收集了什么

不收集。

- 没有账号注册体系:登录走平台扫码(二维码在本机编码绘制),本应用不保存你的密码(它根本拿不到)。
- 不接入任何分析、崩溃上报、广告或推送服务。
- 偏好、历史、搜索词、收藏镜像与崩溃记录全部只写在本机。

## 本机存了什么

| 数据 | 位置 | 清理入口 |
| --- | --- | --- |
| 登录凭据(扫码后的 Cookie 等) | 本机账号盘(DataStore),按账号分桶 | 我的 → 退出 |
| 观看历史、搜索词、收藏镜像 | Room 数据库 | 历史页清空 / 按天数清;收藏页移除 |
| 主题、信息流、播放、弹幕、评论与底栏偏好 | DataStore | 设置页各项 |
| 封面与播放临时文件 | `cacheDir` | 设置 → 存储 → 清理缓存 |
| 最近一次崩溃栈 | `filesDir/crash/last-crash.txt` | 关于 → 上次崩溃记录 → 清除 |

清理缓存**只**清 `cacheDir`,不会删历史、收藏或登录凭据。

## 网络行为

- 所有请求直连 bilibili 的公开接口(HTTP/HTTPS),不经过任何中转服务器。
- 请求携带常规客户端请求头;封面图与播放地址同样直连,不额外代理。
- 不抓取、不上传通讯录、位置、传感器或剪贴板内容。
- 不提供内容解锁、权限绕过或 VIP 破解能力:接口返回什么就展示什么。

## 第三方组件

Media3(播放)、OkHttp(联网)、Coil(取图)、Room / DataStore(存储)等以 Apache-2.0 发布,均在本机处理数据,版权归各自作者。完整依赖以仓库 `gradle/libs.versions.toml` 为准。
