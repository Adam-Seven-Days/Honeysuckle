# 常见问题(FAQ)

> 与 App 内「关于 → 常见问题」同源。

## 账号与登录

**为什么「关注」档要登录?**
关注列表是账号私有数据,游客拿不到。选到关注档时屏上会摆扫码入口;登录成功后这一档自动补取。

**扫码登录安全吗?**
二维码由本机自研编码器生成,生成与轮询只在本机与平台之间完成,没有中转服务器。凭证写入本机账号盘,退出登录即清;平台侧会话会自然过期,本应用不做服务端注销。

**退出登录会怎样?**
本机凭证被清掉,「关注」回到扫码引导,平台收藏夹不再展示;本地收藏镜像、历史与设置仍保留。

## 播放与清晰度

**为什么有些视频没有 1080P / 4K?**
清晰度由平台按身份与内容决定,接口返回哪条轨道就播哪条。本应用不绕过权限,也不做清晰度"解锁"。

**换清晰度会从头播吗?**
不会。换轨从当前播放头重新起播。

**画中画怎么进?**
停在详情页时按 Home,或点控制条上的画中画按钮。没在播放时不会进——空的画中画窗口比没有更让人困惑。

## 评论、弹幕与收藏

**发评论/发弹幕失败怎么办?**
按提示处理:要求登录就去扫码;被风控或提示太频繁就歇一会儿,连点只会等更久;「评论已关闭」类提示表示这个稿件不接受评论。

**评论发出去了为什么没马上显示?**
平台会审核,列表只在重新读第一页后更新。稍后再进来看看。

**关注按钮点了没反应?**
按钮进入忙碌态时不会重复发请求;失败会在按钮下方给一句原因。游客点位是去扫码。

## 历史与缓存

**历史里为什么少了一些看过的视频?**
非视频路由、缺少 `bvid` 的条目会被剔掉,并在列表底部报数;开启「看完即清」时退出播放会删除该条。

**清理缓存会删掉收藏和历史吗?**
不会。清理只碰 `cacheDir`(封面与临时文件),历史、收藏、登录凭据保存在别处,各有各的清理入口。

**断网还能用吗?**
能翻本机历史、本地收藏与搜索词;新内容、评论与相关推荐需要联网。

## 大屏

**平板上怎么用?**
窗口够宽(≥600dp)时底部栏变成左侧导航栏;详情页在 ≥840dp 时分成两栏:左侧播放 / 简介 / 发弹幕 / 关注 / 相关推荐,右侧评论。手机上播放器下面是「简介」与「评论 N」两页,点一下切换;评论按页拉全量,列表滚到底会自动接着取,也可以点「加载更多」。首页卡片按最小宽度自适应成多列。

## 出问题了

**崩溃了怎么办?**
「关于 → 上次崩溃记录」可查看、复制或清除。记录只写在本机 `filesDir/crash/last-crash.txt`,不会自动上传。复制后请自行判断是否包含不希望公开的信息。

**怎么知道装的是哪一版?**
「关于」页顶部的版本号现读自系统包信息,不是写死的字符串。
